NAAM BADALNA NAHI PADEGA — sirf link badlo:
 1. Agar aap apni koi photo/video replace karna chahte ho, to is file me us item ka URL
    badal do aur mujhe bata do — main site me update kar dunga.
 2. Ya phir nayi file ka naam ORIGINAL ke naam par RAKH ke apne hosting/CDN par daal do —
    site automatically wahi dikhayegi (naam same hone chahiye, case bhi same).
 3. Saare links ke aage '?width=NNNN' CDN ka size parameter hai — apne direct link par
    aaye to '?width...' hata dena ya waise hi chhod dena, dono chalega.
 4. Hero video (MP4) replace karne ke liye seedha MP4 link de dena.
